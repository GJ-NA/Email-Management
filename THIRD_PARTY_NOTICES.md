# Third-Party Notices

Email Management is an integration and improvement of the following projects. Please review the current upstream repositories for their complete license text and notices before redistributing a build.

## assast/outlookEmail

- Repository: <https://github.com/assast/outlookEmail>
- Role: base Flask application, account management, Graph / IMAP mail workflows, UI and runtime structure.
- The upstream README identifies the project as MIT licensed.

## fangxiaobaiqaq1/outlook-mail-helper

- Repository: <https://github.com/fangxiaobaiqaq1/outlook-mail-helper>
- License: MIT
- Role: reference for concurrent mailbox verification, receive probing and credential import normalization.
- Its independent PHP application and SQLite database are not embedded in this repository.

## CN-Root/OutlookPanel

- Repository: <https://github.com/CN-Root/OutlookPanel>
